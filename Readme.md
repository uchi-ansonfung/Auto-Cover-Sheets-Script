# First Run Instructions
1. Download the program (.exe file) from the latest [release](https://github.com/uchi-ansonfung/Auto-Cover-Sheets-Script/releases).
2. Dismiss Windows SmartScreen warning (click More Info, then click Run Anyways).

# Usage Instructions
1. Create a folder containing the PDFs to be processed.  Change the filename for each PDF to the text to be displayed on the coversheet (*e.g.*, Exhibit A.pdf == Exhibit A)
2. Open the program.
3. In popup file explorer window, navigate to the folder created in step 1 and click Select Folder.
4. Wait.  The program will close once all PDFs have been processed.
5. Navigate to the folder specified in step 3 and locate the processed PDFs, the filenames of which are prepended with "cover_" (*e.g.*, cover_Exhibit A.pdf).

# What This Program Does
* Adds letter-sized coversheet with centered text corresponding to the filename in 36-point Times New Roman Bold.
* Performs lossless compression on the entire PDF.
* Removes metadata.

# What This Program Doesn't Do
* No OCR.  The program does not change whether a PDF is text-searchable.
